# КМ-сканер (v2): описание для разработчика

Учёт кодов маркировки «Честного Знака» из PDF-этикеток: загрузка PDF, скан кода ручным сканером, отметка «использован», предупреждение «ПОВТОР», выгрузка PDF только со свободными этикетками.

## Архитектура
- Один файл `index.html`, работает без сервера и без бэкенда. Сейчас размещён на GitHub Pages: https://roman-purtow.ru/km-scanner/ (исходная версия: https://darjakucherjavenko-ship-it.github.io/km-scanner/)
- Встроены библиотеки: pdf.js (рендер PDF), декодер DataMatrix, pdf-lib (сборка PDF). Поэтому файл весит около 2,4 МБ.
- База хранится в IndexedDB браузера (`kmscan`, версия 1), хранилища `files` и `codes`. Уникальный индекс `key` = [gtin, serial].
  База привязана к origin, поэтому при смене адреса страницы данные не переносятся. Для переноса есть кнопки «Сохранить базу в файл» и «Загрузить базу из файла».
- Интерфейс на двух языках, RU и 中文 (объект `I18N`).

## Основные функции в коде
- `parseKM(raw)` разбирает строку кода в {gtin, serial, full}. Понимает GS (\x1d), префиксы AIM `]d2` и `]Q3`, скобочный формат (01)(21)(91)(92), а также код без разделителей.
- `handleScan(raw)` ищет код в базе и отмечает его. Статусы: ok / repeat / unknown / bad.
- Блок «приём со сканера» (v2):
  - Буфер склеивает куски, на которые Android разрезает ввод с USB-сканера.
  - Хвосты `91…`/`92…` после уже принятого кода пропускаются.
  - Enter ловится через keydown, keyup, beforeinput и submit. Tab тоже завершает ввод.
  - Курсор подхватывается автоматически, скан работает с любой вкладки.

## Оборудование
- Сканер: проводной USB 2D EVAWGIB в режиме HID-клавиатуры, подключён к Android-планшету (Redmi) через OTG.
- Этикетки: PDF по 100 шт., одна этикетка на страницу (DataMatrix, товар, размер).

## Известные ограничения и пожелания
- База у каждого планшета своя, общей синхронизации между устройствами нет. Если нужна общая база для нескольких планшетов или ноутбуков в разных сетях, потребуется бэкенд: сервер, БД и API, а также перенос логики `findCode` и отметки кода на сервер.
- Выгрузка PDF со свободными кодами работает только из той базы, которая лежит на данном устройстве.
