# КМ-сканер (v2): описание для разработчика

Учёт кодов маркировки «Честного Знака» из PDF-этикеток: загрузка PDF, скан кода ручным сканером, отметка «использован», предупреждение «ПОВТОР», выгрузка PDF только со свободными этикетками.

## Архитектура
- Один файл `index.html`, работает без сервера и без бэкенда. Сейчас размещён на GitHub Pages: https://roman-purtow.ru/km-scanner/
- Встроены библиотеки: pdf.js (рендер PDF), декодер DataMatrix, pdf-lib (сборка PDF). Поэтому файл весит около 2,4 МБ.
- База хранится в IndexedDB браузера (`kmscan`, версия 1), хранилища `files` и `codes`. Уникальный индекс `key` = [gtin, serial].
  База привязана к origin, поэтому при смене адреса страницы данные не переносятся. Для переноса есть кнопки «Сохранить базу в файл» и «Загрузить базу из файла».
- Интерфейс на двух языках, RU и 中文 (объект `I18N`).

## Основные функции в коде
- `parseKM(raw)` разбирает строку кода в {gtin, serial, candidates, ru, full}. Понимает GS (\x1d), префиксы AIM `]d2` и `]Q3`, скобочный формат (01)(21)(91)(92), а также код без разделителей.
  - `fixLayout` переводит строку, набранную в русской раскладке (кириллица вместо латиницы), обратно в QWERTY по положению клавиш.
  - `candidates` — варианты серийника: до GS; первые 13 символов (легпром); до блока `91`/`93`; весь остаток, если он не длиннее 20. Так код принимается, даже если GS потерялся или вместо него пришёл мусор (`]`, `0029`).
- `findAny(p)` проверяет кандидатов по базе и возвращает первую найденную запись.
- `handleScan(raw, keys)` ищет код в базе и отмечает его. Статусы: ok / again / repeat / unknown / bad.
  - `again` («Уже принят только что»): тот же код в течение 10 секунд после «Принято». Сканер прочитал этикетку дважды, это не повтор.
  - Для bad и unknown показывается `showRaw`: что прислал сканер, невидимые символы метками `⟨GS⟩`, длина строки, служебные клавиши, пометка о русской раскладке.
  - 8, 12, 13 или 14 цифр: подсказка «это штрих-код товара, а не код маркировки».
- Блок «приём со сканера» (v2):
  - Буфер склеивает куски, на которые Android разрезает ввод с USB-сканера.
  - Хвосты `91…`/`92…` после уже принятого кода пропускаются.
  - Enter ловится через keydown, keyup, beforeinput и submit. Tab тоже завершает ввод.
  - Курсор подхватывается автоматически, скан работает с любой вкладки.
  - GS сканеры шлют по-разному: F8, Ctrl+] или Alt+0029 на цифровом блоке. Все три способа превращаются в настоящий GS (как в atv-picker, `public/scan-keys.js`).
  - Скан, начатый в поле «Отгрузка», переносится в поле скана, название отгрузки не портится.

## Страница помощи
`scanner-help.html` — инструкция для склада на RU и 中文: как сканировать, что значит каждое сообщение, что делать при повторяющейся ошибке, необязательная настройка сканера и планшета. Ссылки на неё — кнопка «Помощь» в шапке и «Что делать? →» в сообщении об ошибке. Язык общий со сканером (`km_lang` в localStorage). Если меняются тексты статусов в `I18N`, обнови и эту страницу.

## Настройка сканера
Программа терпит ошибки передачи, но надёжнее убрать их в самом сканере (настраивается штрих-кодами из инструкции EVAWGIB; для склада то же самое расписано в `scanner-help.html`):
- оставить только DataMatrix и выключить 1D-штрих-коды, чтобы сканер не ловил EAN на соседней этикетке;
- включить передачу GS (FNC1) и суффикс Enter;
- если на планшете пропадают символы, снизить скорость передачи (задержка между символами);
- выключить непрерывный режим и повторное чтение того же кода;
- на планшете раскладка физической клавиатуры — английская (программа переводит русскую, но так надёжнее).

## Оборудование
- Сканер: проводной USB 2D EVAWGIB в режиме HID-клавиатуры, подключён к Android-планшету (Redmi) через OTG.
- Этикетки: PDF по 100 шт., одна этикетка на страницу (DataMatrix, товар, размер).

## Известные ограничения и пожелания
- База у каждого планшета своя, общей синхронизации между устройствами нет. Если нужна общая база для нескольких планшетов или ноутбуков в разных сетях, потребуется бэкенд: сервер, БД и API, а также перенос логики `findCode` и отметки кода на сервер.
- Выгрузка PDF со свободными кодами работает только из той базы, которая лежит на данном устройстве.
